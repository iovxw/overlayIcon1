# overlayIcon1

最小 C++ 复现，用图片输入/输出模拟 KDE `StatusNotifierItemSource::overlayIcon()` 的绘制逻辑。

Minimal C++ reproduction that simulates KDE `StatusNotifierItemSource::overlayIcon()` with image input and image output.

## 输入

## Input

默认读取子模块中的两张图片：

- `./ksni_overlay_icon_pixmap_bug/data/default256.png`
- `./ksni_overlay_icon_pixmap_bug/data/overlay.png`

By default the program reads these two images from the git submodule:

- `./ksni_overlay_icon_pixmap_bug/data/default256.png`
- `./ksni_overlay_icon_pixmap_bug/data/overlay.png`

## 构建

## Build

```bash
cmake -S . -B build
cmake --build build
```

## 运行

## Run

```bash
./build/overlay_icon_repro
```

也可以显式传入：

You can also pass the paths explicitly:

```bash
./build/overlay_icon_repro ICON_PNG OVERLAY_PNG OUTPUT_DIR
```

## 输出

## Output

程序会按照 KDE 对应函数的相同逻辑生成并写出这些图片：

The program reproduces the same output icon sizes generated by the KDE function and writes:

- `16x16.png`
- `22x22.png`
- `32x32.png`
- `48x48.png`
- `all.png`

默认输出目录：`./outputs`

The default output directory is `./outputs`.
